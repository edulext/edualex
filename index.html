Bypass chặn copy / paste

Cho phép copy / paste vào edunext ( edu lech )

Cách 1: DevTools (Thủ công)
Sao chép mã nguồn trực tiếp từ file console.js.
01
Mở Developer Tools (F12)
Nhấn phím F12 (hoặc Ctrl + Shift + I / Cmd + Option + I).
02
Mở Tab Console & Bỏ chặn Paste
Chuyển sang thẻ Console. Nếu trình duyệt chặn dán mã, nhập dòng sau rồi nhấn Enter:
allow pasting
03
Dán Code & Thực thi
Nhấn Ctrl + V (hoặc Cmd + V) để dán mã vào Console và nhấn Enter.
Cách 2: Bookmarklet (1-Click)
Tạo Bookmark 1 lần, các lần sau chỉ cần bấm nút để kích hoạt.
01
Bật Thanh Dấu Trang
Nhấn Ctrl + Shift + B (Windows) hoặc Cmd + Shift + B (macOS).
02
Tạo Bookmark Mới
Nhấp chuột phải vào thanh Bookmark -> Chọn Thêm trang... (Add page...).
03
Lưu Cấu Hình
Tên: Tùy chọn (ví dụ: Bypass EduNext).
URL: Dán mã Bookmarklet đã copy ở trên -> Bấm Lưu.
04
Kích Hoạt Trên EduNext
Khi làm bài trên EduNext, nhấp trực tiếp nút Bookmark vừa tạo trên thanh công cụ.
Cách 3: Tampermonkey (Tự động)
Sao chép mã UserScript từ file tampermonkey.js.
01
Cài Extension Tampermonkey
Cài đặt tiện ích mở rộng Tampermonkey từ Cửa hàng Chrome / Edge.
02
Tạo Script Mới
Bấm biểu tượng Tampermonkey trên thanh công cụ -> Chọn Create a new script...
03
Dán Mã & Lưu
Bấm nút Copy Mã Tampermonkey ở trên, xóa sạch code cũ trong editor rồi dán vào -> Nhấn Ctrl + S để lưu.
04
Tự Động Kích Hoạt
Mở EduNext, tiện ích sẽ tự chạy ngầm và mở khóa copy/paste hoàn toàn tự động.
Lưu ý bảo mật: Chỉ chạy các đoạn mã từ nguồn đáng tin cậy để tránh nguy cơ lộ thông tin cá nhân.
