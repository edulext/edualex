Bypass chặn copy / paste

Cho phép copy / paste vào edunext ( edu lech )

Cách 1: Chạy qua DevTools (Thủ công)
console.js JavaScript 
Đang tải nội dung file console.js...
Sao chép toàn bộ mã nguồn từ file console.js.
01
Mở Developer Tools (F12)
Nhấn phím F12 (hoặc Ctrl + Shift + I / Cmd + Option + I).
02
Mở Tab Console & Bỏ chặn Paste
Chuyển sang thẻ Console. Nếu trình duyệt chặn dán mã, nhập dòng sau rồi nhấn Enter:
allow pasting
03
Dán Code & Thực thi
Nhấn Ctrl + V (hoặc Cmd + V) để dán mã vào Console và nhấn Enter.
Cách 2: Sử dụng Bookmarklet (Tự động 1-Click)
bookmarklet.js JavaScript URI 
javascript:(function(){['copy','cut','paste','selectstart','contextmenu'].forEach(e=>document.addEventListener(e,x=>x.stopPropagation(),true));})();
Tạo Bookmark 1 lần, các lần sau chỉ cần bấm nút để kích hoạt.
01
Bật Thanh Dấu Trang
Nhấn Ctrl + Shift + B (Windows) hoặc Cmd + Shift + B (macOS).
02
Tạo Bookmark Mới
Nhấp chuột phải vào thanh Bookmark -> Chọn Thêm trang... (Add page...).
03
Lưu Cấu Hình
Tên: Đặt tên tùy chọn (ví dụ: Bypass EduNext).
URL: Dán đoạn mã Bookmarklet đã copy ở trên vào ô URL -> Bấm Lưu.
04
Kích Hoạt Trên EduNext
Khi làm bài trên EduNext, nhấp trực tiếp nút Bypass EduNext trên thanh Bookmark để mở khóa.
Lưu ý bảo mật: Chỉ chạy các đoạn mã từ nguồn đáng tin cậy để tránh nguy cơ lộ thông tin cá nhân.
