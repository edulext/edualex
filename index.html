💡 Bấm nút để sao chép toàn bộ mã nguồn từ file `console.js` vào bộ nhớ tạm.
Hướng dẫn thực thi từng bước
01
Mở Developer Tools (F12)
Bấm phím F12 trên bàn phím (hoặc nhấn phím tắt Ctrl + Shift + I đối với Windows / Cmd + Option + I đối với macOS) để mở bảng Developer Tools.
02
Chuyển sang tab Console & Bỏ chặn Paste
Chuyển sang thẻ Console. Nếu trình duyệt chặn không cho dán mã và hiện cảnh báo bảo mật, hãy gõ chính xác dòng sau rồi nhấn Enter:
allow pasting
03
Dán code & Chạy chương trình
Nhấn phím tắt Ctrl + V (hoặc Cmd + V) để dán đoạn code vừa sao chép ở trên vào Console, sau đó nhấn Enter để chạy.
⚠️ Lưu ý bảo mật: Chỉ chạy các đoạn mã từ nguồn đáng tin cậy để tránh nguy cơ lộ thông tin cá nhân.
